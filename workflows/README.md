# Public workflow

Download [H3_DIRECTOR_STUDIO_V1_PUBLIC.json](H3_DIRECTOR_STUDIO_V1_PUBLIC.json) and drag it onto the ComfyUI canvas after installing H3 Director Studio and the upstream dependencies described in [DEPENDENCIES.md](../docs/DEPENDENCIES.md) and [INSTALLATION.md](../docs/INSTALLATION.md).

The example contains 11 nodes and 14 graph links, including the Deno reference image loader, independent BASE and UPSCALE LoRA stacks, UPSCALE-only Attention backend, VHS video output and Pixaroma timer.

Model and LoRA selections illustrate one configuration and must exist in the user's ComfyUI setup or be replaced with compatible alternatives. Add your own reference images and prompt text.

For setup and troubleshooting, see the [installation guide](../docs/INSTALLATION.md).
